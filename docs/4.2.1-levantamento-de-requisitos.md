# 4.2.1 Levantamento de Requisitos

## Como os requisitos foram levantados

Os requisitos foram coletados por meio de uma entrevista técnica com a Supervisora de Operações, **Naty**, documentando as falhas mais comuns causadas por anotações perdidas em pranchetas no criatório. Também foi realizada a observação direta das fichas de pesagem e evolução de voo que os falcoeiros utilizam no dia a dia.

❓ **A confirmar com o cliente:** 
* Qual a margem exata de variação de peso (em gramas) que o sistema deve aceitar para bloquear ou permitir um voo de forma automática.
* Se o cliente técnico de segurança do aeroporto terá permissão para ver os logs de auditoria de saúde ou apenas o status final de prontidão.

## Da fala à necessidade

| # | Fala | O que é | Necessidade por trás |
|---|---|---|---|
| F1 | "Minha grande preocupação é a falta de informação em tempo real... corro o risco de escalar um gavião e descobrir que estava pesado." (Naty, Supervisora) | Necessidade implícita | Saber com exatidão e antecedência o peso e a aptidão técnica da ave antes de liberá-la para voar em área operacional. |
| F2 | "Hoje em dia o controle é feito de um jeito todo bagunçado, cada hora em um lugar ou no papel." (Falcoeiro) | Solução | Unificar as marcações de alimentação, peso e exames médicos em uma base digital integrada para evitar perdas. |
| F3 | "Preciso receber avisos rápidos quando o bicho estiver fora do peso ideal ou com treino atrasado." (Naty, Supervisora) | Solução | Monitorar desvios nos indicadores biológicos das aves de forma ativa para agir antes que o animal fique inapto. |

## Histórias de usuário

| # | História de usuário | Veio de |
|---|---|---|
| HU01 | Como **Supervisor**, quero **consultar o indicador de prontidão de qualquer ave**, para **autorizar voos operacionais apenas com animais aptos**. | F1 |
| HU02 | Como **Falcoeiro**, quero **registrar o peso matinal e a alimentação diária**, para **manter as métricas de saúde da ave visíveis para a supervisão**. | F2 |
| HU03 | Como **Falcoeiro**, quero **atualizar o progresso dos treinos de voo livre**, para **comprovar quais técnicas a ave domina**. | F1, F2 |
| HU04 | Como **Supervisor**, quero **receber alertas automáticos de desvios de peso**, para **ajustar as dietas antes que ocorram falhas de controle**. | F3 |

## Requisitos funcionais

| # | Nome | Requisito | Veio de |
|---|---|---|---|
| RF01 | Cadastrar ave | O sistema deve cadastrar os perfis individuais das aves com suas respectivas características e restrições. | Escopo 4.1 |
| RF02 | Registrar refeição | O sistema deve registrar as refeições diárias e suplementações oferecidas para cada animal. | HU02 |
| RF03 | Registrar atendimento | O sistema deve registrar as pesagens matinais, consultas médicas e tratamentos veterinários executados. | HU02 |
| RF04 | Registrar evolução | O sistema deve registrar o progresso e o desempenho nos cronogramas de treinamento de voo. | HU03 |
| RF05 | Validar prontidão | O sistema deve checar o status de peso, alimentação e treino antes de liberar uma requisição de missão. | HU01 |
| RF06 | Disparar alertas | O sistema deve notificar os usuários sobre desvios críticos de peso ou atrasos de manejo. | HU04 |

## Requisitos não funcionais

| # | Categoria | Requisito | Veio de |
|---|---|---|---|
| RNF01 | Dispositivo / Acesso | O sistema deve funcionar como uma aplicação web responsiva em computadores e celulares. | características da 4.1 |
| RNF02 | Segurança | O sistema deve exigir autenticação por login e senha criptografada para liberação de acessos. | características da 4.1 |
| RNF03 | Desempenho | O sistema deve processar as consultas de status e validações de missões in menos de 2 segundos. | características da 4.1 |
| RNF04 | Segurança / Auditoria | O sistema deve registrar logs imutáveis de todas as alterações feitas nos dados biológicos e de saúde. | características da 4.1 |

## Conferência com a 4.1

| Item do escopo (4.1) | Requisitos |
|---|---|
| O sistema cadastrar o perfil de cada ave de rapina com identificação da anilha, espécie, peso padrão e restrições. | RF01 |
| O sistema registrar as refeições diárias, pesagens matinais e acompanhamentos de saúde veterinária. | RF02, RF03 |
| O sistema acompanhar a evolução dos treinos de voo e quais técnicas de caça ou retorno o animal já domina. | RF04 |
| O sistema checar se a ave atende aos parâmetros rígidos de peso e treino antes de permitir sua liberação para uma missão. | RF05 |
| O sistema avisar a equipe com alertas visuais se alguma ave estiver com o peso crítico desregulado ou sem manejo recente. | RF06 |

_Toda história tem requisito? Todo requisito tem origem? O que a conferência mudou?_
**Sim. Todas as histórias viraram requisitos e nenhum requisito foi inventado do nada. A conferência apenas dividiu o antigo item de registros em dois (**RF02** e **RF03**) para seguir a regra de deixar apenas um verbo por requisito, garantindo que o escopo e o levantamento fiquem 100% amarrados.**
